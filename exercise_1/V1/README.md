# SRRS V1 — Baseline (SRRS v1.0)

This is the instructor-provided baseline for Unit 1.

## Functionality

- Train search
- Seat availability
- Passenger registration
- Ticket booking
- Ticket cancellation

## Unit 1 purpose

Students use this version to establish their GitHub repository and then
implement a controlled functional change through an Issue, feature branch,
commit(s), Pull Request and peer review.

## Suggested Unit 1 change

Passenger Booking History.

The student should implement this change through the GitHub workflow rather
than modifying `main` directly.
