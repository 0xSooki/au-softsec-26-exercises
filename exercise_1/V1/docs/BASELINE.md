# V1 Baseline Description

## System boundary

The application is an in-memory teaching application. It does not connect to
a real railway database, payment gateway or external service.

## Core entities

- Train
- Passenger
- Booking

## Baseline operations

1. Search trains
2. Check seat availability
3. Register passenger
4. Book ticket
5. Cancel ticket

## Security teaching note

The baseline is deliberately small so students can read and understand it.
It should be treated as educational code, not production software.

Students should establish the V1 baseline in GitHub before making the Unit 1
functional change.
